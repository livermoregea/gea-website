# Science at Stockmens Park image

`love-wave.svg` is the current illustration: an original, simplified, top-down vector graphic created for GEA. Blue indicates wave travel; teal indicates horizontal motion perpendicular to wave travel. The apparent up/down direction on the page is motion across the ground in a top-down view, not vertical displacement. Tile displacements are illustrative, not to scale.

- Scientific reference: https://www.iris.edu/hq/inclass/animation/lovewave_motion
- Created: October 1, 2026
- No artwork from the reference was copied.
